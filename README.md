# Digital Twin für den Automotive After-Sales

Prototypischer Demonstrator eines digitalen Zwillings für den After-Sales-Service der Automobilindustrie. Der Demonstrator veranschaulicht anhand synthetischer Fahrzeugdaten ein Szenario zur zustandsbasierten Serviceunterstützung am Beispiel des Bremsbelagverschleißes. Die Anwendung umfasst die Darstellung des Fahrzeugzustands, eine vereinfachte Prognose, eine What-if-Simulation sowie die Bereitstellung von Serviceinformationen.

Der Demonstrator wurde im Rahmen einer Bachelorarbeit mit Python und Streamlit entwickelt.

**Hinweis:** Alle dargestellten Fahrzeugdaten, Statusgrenzen und Verschleißparameter sind synthetisch und dienen ausschließlich der prototypischen Veranschaulichung.
